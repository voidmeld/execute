# Roblox extension

Use this index to find the reusable rules for Roblox experiences and the owner of each rule.
The adopter keeps its universe, place and group IDs, operator names, build commands and product architecture. They do not belong here.

- [Integration](INTEGRATION.md): the values that the adopter must declare.
- [Roblox operations](docs/ROBLOX.md): account and destination, the verification ladder, Studio, persistence, live client runs, admission gates, assets and source authority.
- [Generative assets](docs/ROBLOX-GENERATIVE-ASSETS.md): load it only for generative-asset work.

For scenario play and captures, follow the [interactive QA extension](../interactive-qa/README.md).
Follow the core [external-action procedure](../../docs/PLAYBOOK.md#external-actions).
An assigned scratch grant can permit reversible generation and staging in its exact DataModel under the [project authority](../../AGENTS.md#safety-rules).
It grants no durable publication, no credentials, no permission changes and no new destination.
