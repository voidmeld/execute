# Optional extensions

This index lists the reusable domain rules that an adopter selects.
Extensions are separate from harness adapters. They change neither the role authority nor the operating loop.

- [Luau](luau/README.md): landing, scoped check selection, authority, retention and worktree-setup modules for adopter tooling.
- [Interactive QA](interactive-qa/README.md): the evidence rules for a product that a person operates: captures, scenarios, input and release.
- [Roblox](roblox/README.md): account and destination boundaries, the four-tier verification ladder, Studio ownership, persistence, assets and generative-asset production.

To adopt an extension:

1. Copy only the selected files.
2. Merge their irreversible-loss rules into the project AGENTS.
3. Link their procedures from the project PLAYBOOK.
4. Record the source commit in ADOPTION.
5. Delete unused guidance.

Put generic lessons in the core. Put stable domain lessons in the extension. Keep incident records in the adopting project.
