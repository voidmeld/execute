# Optional extensions

Select only the domain rules that the project needs. Extensions grant no role authority and do not change the
operating procedure.

- [Luau](luau/README.md): common operations for project tools.
- [Interactive QA](interactive-qa/README.md): evidence for products with an interface.
- [Roblox](roblox/README.md): platform operations and asset production.

## Adoption

1. Copy the selected files.
2. Merge rules against irreversible loss into the project AGENTS.
3. Link procedures from the project PLAYBOOK.
4. Record the source commit in ADOPTION.
5. Delete unused guidance.

Put generic lessons in the core. Put stable domain lessons in the extension. Keep incident records in the
adopting project.
