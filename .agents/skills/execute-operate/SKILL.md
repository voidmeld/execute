# Work an assignment

Read `AGENTS.md` at the root of the assigned project worktree for its hard rules, commands and grants.
Use the project's backlog or the assigned [helper brief](../../../docs/helper-brief.md).
Follow the [operating guide](../../../docs/OPERATING.md) through the next observable result.
A helper returns the change and checks to the lead. If progress stops, use the guide's stall check.
