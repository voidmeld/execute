# Backlog

List the owner's requests in priority order and quote each one in the owner's words.
Under each request, briefly describe what someone can see or do when the work is complete.
For example, if the request is “Remember my filter”, the filter should still be selected after a reload.

- [ ] “[Owner's highest priority request]”
  This is done when [what a user can see or do].
- [ ] “[Next request]”
  This is done when [result someone can observe].

Check off each item when it's done. If an item is blocked, add a note beneath it explaining what
it's waiting for and what to do next.
